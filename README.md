# The Winter Day – البرنامج التفاعلي

موقع برنامج فعالية The Winter Day (Elevate Events)، يعرض الفقرات بمواعيدها وأماكنها.

## الملفات
- `index.html` هيكل الصفحة
- `style.css` التصميم بألوان هوية الفعالية
- `app.js` التفاعل: البحث والتصفية و«جدولي» و«الآن والتالي»
- `data.js` **كل المحتوى**، وهو الملف الوحيد اللي يحتاج تعديل

## تحديث البرنامج
افتحي `data.js` وعدّلي الفقرات في `SESSIONS` (الوقت، العنوان، المكان، الوصف). المواعيد الحالية تجريبية.

## تجربة يوم الفعالية قبل موعده
أضيفي `?now=10:45` لنهاية الرابط، ويشتغل الموقع كأن الساعة 10:45 يوم الفعالية.
